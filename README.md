# Afaris Music Studio

Projet Symfony realise sans CMS pour presenter un studio creatif, ses actualites et son backoffice d'administration.

## Application en ligne

- https://studio.afaris.be

## Fonctionnalites

- page d'accueil avec les dernieres actualites
- liste des actualites
- detail d'une actualite avec commentaires et signalement
- page de presentation du studio
- page de contact
- inscription et connexion
- backoffice de gestion des posts, commentaires, membres et medias

## Compte admin de verification

- identifiant : `AfarisAdmin`
